# Prep Backend

Backend API service for the Prep project.

## Setup
1. Use Node.js 22 or compatible.
2. Install dependencies: `npm ci`
3. Copy `.env.example` to `.env` and set required local secrets/configuration.
4. Run the scripts defined in `package.json` for development, type-checking, build, and tests.

Never commit real credentials or production `.env` files. Configure the frontend origin and database/API secrets in your deployment environment.
